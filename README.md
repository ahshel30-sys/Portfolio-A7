# Ahmed Shaker - Portfolio

موقع Portfolio ثابت مبني بـ HTML وCSS وJavaScript، ويعرض أربعة مشاريع تجريبية، منها NŪRA SKIN. جاهز للنشر على Vercel مباشرة من GitHub.

## التشغيل المحلي

```bash
python3 -m http.server 4173
```

افتح `http://localhost:4173`.

## النشر على Vercel من GitHub

1. ادفع المشروع إلى الفرع `main`.
2. افتح Vercel واختر [Add New Project](https://vercel.com/new).
3. استورد مستودع `ahshel30-sys/Portfolio-A7`.
4. اترك Framework Preset على `Other`.
5. اجعل Root Directory هو جذر المستودع.
6. اضغط Deploy. بعد ربط المستودع، سينشر Vercel تلقائيًا أي تحديث جديد يتم دفعه إلى `main`.

لا يحتاج المشروع إلى أمر build أو متغيرات بيئة. اختر `Other` كإطار العمل، واترك Build Command فارغًا وOutput Directory على الجذر. جميع ملفات العرض والأصول موجودة في المستودع.

## المشاريع

تتضمن الأعمال المعروضة مشاريعًا تجريبية مستقلة وليست أعمالًا مدفوعة لعملاء. أحدثها NŪRA SKIN، متجر عناية بالبشرة بمحتوى عربي واتجاه RTL، مع سلة تسوق تجريبية. العلامة التجارية والأسعار والتقييمات وتفاعلات الشراء للعرض فقط وليست خدمات إنتاجية.
